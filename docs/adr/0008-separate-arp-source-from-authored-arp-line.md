# Separate Arp Source from authored Arp Line

Arp Source remains a sustained pitch set whose articulation belongs to the artist's Ableton Arpeggiator, while Arp Line is a separate Musical Role with extension-authored notes, rests, gates, accents, octave displacement, and probability. Combining them as modes of one role would hide two incompatible ownership contracts behind the same name and make orchestration ambiguous.
